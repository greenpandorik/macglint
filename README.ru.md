# MacGlint

**Понятный взгляд на состояние Mac.**

Будущий монитор системы в строке меню macOS: CPU, память, процессы, история и личные уведомления.

[English](README.md) · [Макеты](docs/design/README.md) · [План разработки](docs/ROADMAP.md) · [Предложить идею](https://github.com/greenpandorik/macglint/issues/new/choose)

</div>

> **В первую очередь я делаю MacGlint для себя, с помощью ИИ.** Хочется удобный, современный монитор системы, которым приятно пользоваться каждый день. ИИ помогает прорабатывать дизайн, писать документацию и разрабатывать проект. Публикую всё открыто — возможно, кому-то ещё это окажется полезно.

> **Сейчас это концепция и спецификация.** Исходного кода приложения, установщика и готовых релизов пока нет. Все изображения — созданные с помощью ИИ макеты с условными данными, а не скриншоты работающей программы.

## Установка — в плане

**Скачать приложение пока нельзя.** Планируем простой сценарий: скачать DMG из GitHub Releases, перетащить MacGlint в «Программы» и запустить. Публичные сборки будут готовиться с подписью Developer ID и нотариализацией Apple.

Для пользователей Homebrew появится дополнительный способ установки после публикации и проверки пакета. Обновления внутри приложения — следующий этап. Подробности: [план установки и выпуска](docs/INSTALLATION.md).

Рабочая кнопка скачивания и команда установки появятся здесь вместе с первой проверенной сборкой.

## Идея

Открыть небольшую панель, увидеть состояние Mac и при необходимости раскрыть подробности: какое приложение создаёт нагрузку, что происходило раньше и что можно завершить.

Основной сценарий: **обзор → приложение → процесс → действие**.

## Что планируется

| Возможность | Для чего |
|---|---|
| **Компактный обзор** | CPU, память, сеть и батарея; выбор постоянно видимых показателей в строке меню. |
| **Подробные процессы** | Поиск, сортировка, раскрытие приложений и график выбранного процесса. |
| **Управление процессами** | Обычное завершение и отдельное подтверждение принудительного завершения доступного процесса. |
| **Две темы** | Светлая, тёмная и переключение вслед за macOS. |
| **История нагрузки** | Посмотреть, что происходило во время замедления, с отметками алертов. |
| **Личные правила** | Пороги и длительность превышения для всего Mac или приложения, нехватки памяти и места на диске. |
| **Уведомления без спама** | Игнорирование коротких скачков, пауза, исключения и подавление повторов. |
| **Закреплённое окно** | Наблюдать за нагрузкой, пока работаешь в других приложениях. |

Это запланированные функции. Автоматического завершения процессов по уведомлению не будет.

## Что со вкладками Safari

Safari — мой основной браузер. Хочется видеть, какая именно вкладка расходует ресурсы, но **точную привязку CPU и памяти к вкладкам ещё нужно проверить**.

Мониторинг доступных процессов Safari входит в план. Названия сайтов не будут подставляться к процессам по догадке. В [заметке об исследовании](docs/research/safari.md) описано, что известно и что предстоит проверить.

## Разработка и данные

Предлагаемая основа — **Swift, SwiftUI и AppKit**. Первая цель — личный Mac на Apple Silicon. Минимальная версия macOS и поддержка других конфигураций ещё не определены.

История и настройки проектируются для локального хранения. Помощь ИИ в разработке не предполагает отправку данных о процессах или вкладках в ИИ-сервис.

| Этап | Состояние |
|---|---|
| Визуальное направление и макеты двух тем | Готово |
| Спецификация и этапы разработки | Подготовлены |
| Проверка привязки вкладок Safari | Предстоит |
| Рабочее нативное приложение | Разработка ещё не начата |
| Установочная сборка | Пока нет |

Инструкция по сборке и установке появится вместе с рабочим приложением.
