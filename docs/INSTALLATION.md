# Установка и обновления MacGlint

**Статус: план распространения, не готовая инструкция установки.** Приложение, DMG, Homebrew-пакет и обновления пока не созданы. Не требуется устанавливать инструменты разработчика, чтобы следить за проектом.

## Основной способ: скачать и перетащить

После первой рабочей публикации основной сценарий будет таким:

1. Нажать «Скачать для Mac» в README.
2. Открыть скачанный DMG.
3. Перетащить `MacGlint.app` на расположенную рядом ссылку «Программы».
4. Запустить MacGlint из «Программ». Приложение покажет, где находится его значок в строке меню.

Внутри образа — приложение, ссылка на `/Applications` и короткая подсказка. Пользователь не должен собирать исходники, устанавливать Xcode или запускать сценарий в терминале.

В первом выпуске планируется одна явно обозначенная сборка для Apple Silicon. Минимальная macOS будет указана рядом со скачиванием после проверки. Поддержка Intel или универсальная сборка появится только после проверки на соответствующей конфигурации.

## Подпись и проверка Apple

Публичный DMG планируется распространять с приложением, подписанным Developer ID, и успешной нотариализацией Apple. Это штатный путь распространения вне Mac App Store: [Developer ID и Gatekeeper](https://developer.apple.com/help/account/certificates/create-developer-id-certificates).

До выпуска потребуется настроить сертификат Developer ID владельца проекта и доступ к сервису нотариализации. Их наличие пока не проверено. Получение учётной записи, оплата участия и выдача доступа не выполняются автоматически в рамках подготовки документации.

Релизный процесс должен проверить подпись, результат нотариализации и прикрепление билета проверки к распространяемым объектам. Финальный файл проверяется после скачивания через браузер на тестовом Mac. Обычное системное подтверждение первого открытия допустимо; отключение Gatekeeper или удаление карантинных атрибутов не является частью инструкции.

## Дополнительный способ: Homebrew

Для пользователей с установленным Homebrew планируется собственный tap с cask-пакетом. Он будет устанавливать тот же проверенный DMG из GitHub Releases; наличие приложения в общем каталоге Homebrew для этого не требуется. Основа: [документация Homebrew о taps](https://docs.brew.sh/How-to-Create-and-Maintain-a-Tap) и [Cask Cookbook](https://docs.brew.sh/Cask-Cookbook).

Предлагаемое имя будущего tap-репозитория: `greenpandorik/homebrew-macglint`. Будущая команда: `brew install --cask greenpandorik/macglint/macglint`.

**Эта команда пока не работает: tap и cask ещё не опубликованы.** В основной README она появится только после успешной проверки установки. Действующая версия Homebrew может запросить доверие к стороннему источнику; поддерживаемый сценарий нужно проверить перед выпуском.

Cask будет содержать конкретную версию, ссылку на неизменяемый файл выпуска, его SHA-256, название приложения и требования к системе. Для каждого выпуска потребуется обновить версию и контрольную сумму. Не использовать фиктивные адреса, пустые пакеты или отключение проверки SHA-256.

## Первый запуск

- Сразу показать обзор и объяснить расположение значка в строке меню.
- Предложить выбрать системную, светлую или тёмную тему.
- Запрашивать разрешение на уведомления при включении алертов; отказ не должен мешать мониторингу.
- Автозапуск при входе включается отдельно по желанию пользователя.
- Возможное расширение Safari подключается отдельно, если исследование подтвердит его пользу.

Основной сценарий не требует аккаунта MacGlint. Права на установку в выбранную папку определяются настройками самого Mac; отсутствие административных прав не обходится.

## Обновления

Для первой версии: новый DMG с заменой приложения, а для Homebrew — обновление через менеджер пакетов. Правила, настройки и история хранятся отдельно от приложения и должны сохраняться при замене версии.

Следующий этап — пункт «Проверить обновления» и предложение установить новую версию внутри приложения через [Sparkle](https://sparkle-project.org/documentation/). Загрузки передаются по HTTPS, архивы обновлений подписываются, автоматические проверки включаются по выбору пользователя. Перед интеграцией проверить совместимость с выбранной версией macOS и поведение установки через Homebrew, чтобы два механизма не конфликтовали.

Сетевой запрос проверки версии — отдельное действие: он не должен включать список процессов, историю нагрузки или адреса вкладок. Без проверки обновлений локальный мониторинг продолжает работать.

## Удаление

Планируемый сценарий: завершить MacGlint через его меню и перенести приложение в Корзину; при установке через Homebrew использовать удаление cask. Настройки и историю можно отдельно очистить из приложения перед удалением. Обычное удаление не должно молча уничтожать пользовательские данные.

## Подготовка первого выпуска

- [ ] Создать рабочее приложение и выбрать минимальную macOS.
- [ ] Подготовить иконку, стабильный идентификатор приложения и версию сборки.
- [ ] Собрать, подписать и нотариализовать дистрибутив; проверить билеты и подписи.
- [ ] Создать DMG со ссылкой на «Программы» и краткими инструкциями.
- [ ] Проверить скачивание, установку, первый запуск и удаление на тестовой системе.
- [ ] Проверить замену более старой тестовой сборки без потери настроек.
- [ ] Подготовить GitHub Release с DMG, контрольной суммой, требованиями и перечнем реально работающих функций.
- [ ] Проверить опубликованный файл, затем добавить работающую кнопку скачивания в оба README.
- [ ] Создать tap и cask, проверить установку/обновление/удаление и затем опубликовать команду Homebrew.

Пока эти шаги не выполнены, главная страница сообщает о стадии проектирования и не предлагает несуществующую загрузку.
