# Установка MacGlint

## Уже доступно: локальная сборка

Рабочая предварительная версия 0.4.0. Требования: macOS 14+, инструменты Xcode со Swift 5.9+ и Git. Проверено на Apple Silicon / macOS 26 / Xcode 26.4. Intel и минимальная macOS пока не проверены на реальном устройстве.

```sh
git clone https://github.com/greenpandorik/macglint.git
cd macglint
./scripts/build-app.sh
open build/MacGlint.app
```

Чтобы получить установочный образ:

```sh
./scripts/make-dmg.sh
```

В папке `build/` появится `MacGlint-0.4.0-arm64.dmg` на Apple Silicon (на Intel — `x86_64`). Откройте его, перетащите MacGlint на ссылку Applications и запускайте из «Программ». Сначала завершите ранее запущенный MacGlint через меню приложения.

Сборка подписывается локальной ad-hoc подписью. Она **не нотариализована Apple**. Это способ собрать приложение из исходников на своём Mac, а не готовый беспроблемный дистрибутив для скачивания. Не отключайте Gatekeeper. Публичной ссылки на проверенный подписанный DMG пока нет.

## Первый запуск

Появляется значок в строке меню и компактный обзор. «Открыть полное окно» открывает отдельное изменяемое окно с процессами, ростом памяти, историей и настройками. Шестерёнка ведёт прямо в настройки. Клик вне мини-панели или Esc скрывает только её. Закрытие полного окна не останавливает мониторинг. Светлая/тёмная тема, показатели строки меню и закрепление окна уже доступны.

Полное окно закрывается стандартной красной кнопкой macOS слева сверху или ⌘W; мониторинг остаётся в строке меню. «Мини-панель» внизу боковой панели убирает большое окно и открывает компактный обзор (⌘0). Кнопка «Выйти» полностью завершает MacGlint и останавливает мониторинг (⌘Q).

Разрешение на уведомления запрашивается только по кнопке в настройках. Без разрешения мониторинг и запись событий работают. Автозапуск при входе — отдельный переключатель; сначала установите приложение в «Программы».

Приложение не требует аккаунта, доступа к вкладкам Safari или административного помощника. Сборка не обходит системные ограничения на процессы.

## Обновление и удаление

Для локального обновления завершите приложение, соберите новую версию и замените `.app`. Настройки и история находятся отдельно и сохраняются. Автоматического обновления пока нет.

Для удаления завершите MacGlint, отключите его автозапуск, если включали, и перенесите `.app` в Корзину. Историю можно отдельно очистить в настройках; обычное удаление приложения не стирает её молча.

## После обновления до 0.3.0

Старая история и настройки сохраняются. Подробности приложений появляются только для новых срезов. Раздел «Рост памяти» требует минимум минуту непрерывных наблюдений после запуска; период сравнения постепенно увеличивается до 10 минут.

## Интерфейс 0.4.0

Настройки разделены на «Основные», «Уведомления» и «О приложении». Тема, строка меню, автозапуск и очистка истории находятся в основных настройках; правила и исключения — в уведомлениях. Переход из события сразу открывает редактор нужного правила. Дублирующий крестик внутри окна удалён.
