# Установка MacGlint

Состояние на 14 октября 2026 года: **0.4.0, предварительная версия**. Исходники доступны, приложение и DMG собираются, проверки GitHub Actions проходят. [GitHub Releases](https://github.com/greenpandorik/macglint/releases) пока не содержит опубликованного выпуска.

## Как установить сейчас

| Способ | Что доступно |
|---|---|
| Скачать обычный публичный установщик | Пока нет: ещё не опубликован Release |
| Получить DMG от автора | Готова локальная сборка 0.4.0 для Apple Silicon; без Developer ID и нотариализации |
| Собрать из исходников | Доступно сейчас; инструкции ниже |
| GitHub Actions | Тестовые DMG в артефактах успешных сборок, срок хранения 14 дней; не постоянный канал установки |
| Homebrew / обновление из приложения | Пока не реализованы |

### Если вам передали готовый DMG

Для локального `MacGlint-0.4.0-arm64.dmg` нужен Mac с Apple Silicon (M1 и новее). Минимальная система — macOS 14; реально проверены Apple Silicon и macOS 26. Для запуска готовой сборки **не нужны Xcode, Swift или Git**.

1. Завершите старую версию MacGlint через «Выйти» или ⌘Q.
2. Откройте DMG и перетащите MacGlint на ярлык Applications («Программы»). При обновлении замените старое приложение.
3. Извлеките образ и запускайте MacGlint из «Программ».
4. Появится значок в строке меню. Разрешение на уведомления и автозапуск настраиваются отдельно по желанию.

Текущий DMG имеет локальную ad-hoc подпись и **не прошёл нотариализацию Apple**. После скачивания или передачи macOS может заблокировать первый запуск. Apple описывает отдельное разрешение для доверенного приложения через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»; доступность зависит от предупреждения и политики Mac. Это не обязательный шаг и не гарантия запуска. Не обходите сообщение о вредоносном или повреждённом приложении: запросите проверенную сборку. Не отключайте Gatekeeper целиком и не удаляйте карантин командами. [Инструкция Apple](https://support.apple.com/102445).

Передача DMG знакомым — способ тестирования, а не обещание беспроблемной установки для всех. Сборка arm64 не подходит Intel Mac.

### Сборка из исходников

Нужны macOS 14+, Git и инструменты Xcode с компилятором Swift 5.9+. Проверенная конфигурация: Xcode 26.4 / macOS 26 / Apple Silicon; старый минимальный набор инструментов ещё не проверен отдельно.

```sh
git clone https://github.com/greenpandorik/macglint.git
cd macglint
./scripts/build-app.sh
open build/MacGlint.app
```

Чтобы получить установочный образ:

```sh
./scripts/make-dmg.sh
```

В `build/` появится `MacGlint-0.4.0-arm64.dmg` на Apple Silicon или `MacGlint-0.4.0-x86_64.dmg` при сборке на Intel. Скрипты собирают только архитектуру текущего Mac, не универсальный бинарник. Intel пока не проверен на устройстве. Установите приложение через полученный DMG, как описано выше. Скрипт подписывает сборку локально; платная учётная запись Apple для этого не нужна.

## Первый запуск и управление

Клик по значку открывает мини-панель. «Открыть полное окно» ведёт к процессам, росту памяти, истории и настройкам. Шестерёнка открывает настройки. Esc и клик вне мини-панели скрывают её.

Полное окно закрывается стандартной красной кнопкой macOS слева сверху или ⌘W; мониторинг остаётся в строке меню. «Мини-панель» и ⌘0 убирают большое окно. «Выйти» и ⌘Q полностью завершают приложение. Если значок не виден среди других значков, повторно откройте MacGlint из «Программ» — появится полное окно.

В настройках 0.4.0:

- **Основные:** тема, показатели строки меню, запуск при входе, очистка истории.
- **Уведомления:** разрешение и показ баннеров, правила, паузы и исключения.
- **О приложении:** версия, сведения о проекте и ссылка на GitHub.

Без разрешения на уведомления мониторинг и запись событий работают. Для автозапуска сначала установите приложение в «Программы». [Все функции и сочетания клавиш](FEATURES.md).

## Обновление и удаление

Автообновления пока нет. Завершите приложение, установите новую сборку поверх старой и запустите её. При сборке из репозитория сначала получите изменения через `git pull --ff-only`, затем повторите сборку и установку.

История и настройки при обычной замене приложения сохраняются. Срезы приложений доступны только с момента работы версии 0.3.0 и новее. После каждого запуска рост памяти требует минимум минуту наблюдений; сравнение постепенно расширяется до десяти минут.

Для удаления выключите «Запускать при входе в macOS», завершите MacGlint и переместите приложение из «Программ» в Корзину. Историю при желании очистите в настройках заранее. Удаление `.app` само по себе не удаляет пользовательские настройки и файл истории; их расположение описано в [DEVELOPMENT.md](DEVELOPMENT.md).

## Что осталось для удобного публичного выпуска

Цель: **скачать DMG → перетащить в «Программы» → открыть**. Для этого не требуется публикация в Mac App Store.

1. **Учётная запись Apple Developer Program и сертификат Developer ID Application.** Если подходящей подписки ещё нет, Apple указывает стоимость 99 USD в год или местный эквивалент. Подписка нужна издателю, не пользователям. Регистрация, доступность и оплата зависят от условий Apple. [Участие в программе](https://developer.apple.com/programs/whats-included/).
2. **Подготовить подписанную сборку.** Настроить подпись распространяемых исполняемых файлов, Hardened Runtime и необходимые разрешения. Сейчас скрипт использует только ad-hoc подпись. Секреты и сертификаты не хранятся в репозитории.
3. **Пройти нотариализацию и прикрепить билет Apple к дистрибутиву.** Это проверка распространяемого ПО, отдельная от проверки приложения для App Store. Проверить итоговый DMG и обычное первое открытие. [Требования Apple](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution), [Developer ID](https://developer.apple.com/developer-id/).
4. **Проверить скачанную сборку на другом Mac.** Первый запуск, уведомления, автозапуск, обновление поверх предыдущей версии, работа в фоне и закрытие окна. Отдельно подтвердить поддержку macOS 14; Intel публиковать только после сборки и проверки, либо первый выпуск явно ограничить Apple Silicon.
5. **Опубликовать GitHub Release.** Постоянный DMG, контрольная сумма SHA-256, список изменений, требования и заметные ограничения. Добавить в README ссылку на скачивание. Обычный системный вопрос при первом открытии скачанного приложения может оставаться даже у подписанного выпуска.
6. **Выбрать лицензию проекта.** Сейчас файла LICENSE нет; это отдельное решение автора перед заявлением об открытой лицензии и широким распространением исходников.

После первого проверенного выпуска: Homebrew cask, автоматические обновления через Sparkle, английский интерфейс. Эти удобства не обязательны для первой установки через DMG. Точные вкладки Safari, недельная история и прочие новые возможности также не блокируют выпуск имеющихся функций.
