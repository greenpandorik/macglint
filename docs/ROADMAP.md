# Этапы MacGlint

Состояние на 14 октября 2026 года: рабочая нативная предварительная версия 0.1.0, без подписанного публичного релиза.

## Реализовано

- [x] Направление Air, компактная панель и раскрытый режим.
- [x] Реальные CPU, память, давление памяти, сеть, батарея и свободный диск.
- [x] Светлая, тёмная и системная темы; настраиваемая строка меню.
- [x] Поиск, сортировка, группы процессов, краткий график, закрепление окна.
- [x] Подтверждаемое завершение, проверка владельца и идентичности процесса.
- [x] Локальная история за 24 часа и отметки событий.
- [x] Личные правила, длительность, повторный интервал, исключения и пауза.
- [x] Интеграция системных уведомлений и опционального автозапуска.
- [x] Локальные `.app`/DMG, тесты и автоматическая сборка.

## Перед обычным публичным выпуском

- [ ] Подпись Developer ID и нотариализация Apple.
- [ ] Проверка скачанного DMG на чистом Mac, включая уведомления и автозапуск.
- [ ] Проверка macOS 14, Intel, разных экранов и длительной фоновой нагрузки.
- [ ] Дополнительная проверка доступности и англоязычный интерфейс.
- [ ] GitHub Release и Homebrew cask. [Установка](INSTALLATION.md).

## Следующие возможности

- [ ] Проверить достоверное сопоставление процессов с вкладками Safari отдельным прототипом. До подтверждения показывать процессы WebKit без названий сайтов.
- [ ] История за семь дней с агрегацией и экспорт.
- [ ] Более гибкие исключения по контексту работы, например тишина во время использования Figma.
- [ ] Обновления внутри приложения через Sparkle.

У проекта нет обещанного графика выпусков. Реальные ограничения текущей версии перечислены в [DEVELOPMENT.md](DEVELOPMENT.md).
