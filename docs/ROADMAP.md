# Этапы MacGlint

Состояние на 14 октября 2026 года: рабочая нативная предварительная версия 0.4.0, без подписанного публичного релиза.

## Реализовано

- [x] Направление Air, компактная панель и раскрытый режим.
- [x] Реальные CPU, память, давление памяти, сеть, батарея и свободный диск.
- [x] Светлая, тёмная и системная темы; настраиваемая строка меню.
- [x] Поиск, сортировка, группы процессов, краткий график, закрепление окна.
- [x] Подтверждаемое завершение, проверка владельца и идентичности процесса.
- [x] Локальная история за 24 часа и отметки событий.
- [x] Выбор момента на графике, срезы активных приложений и подробные карточки алертов.
- [x] Рост памяти за период до 10 минут с учётом перезапусков и пропусков.
- [x] Пауза отдельного правила на час и переход из события к его настройке.
- [x] Личные правила, длительность, повторный интервал, исключения и пауза.
- [x] Интеграция системных уведомлений и опционального автозапуска.
- [x] Локальные `.app`/DMG, тесты и автоматическая сборка.
- [x] Компактный интерфейс 0.4.0: три раздела настроек, плоские списки и стандартное закрытие окна.
- [x] [Полное описание функций](FEATURES.md) и [инструкция установки](INSTALLATION.md).

## Перед обычным публичным выпуском

- [ ] Подпись Developer ID и нотариализация Apple.
- [ ] Проверка скачанного DMG на чистом Mac, включая уведомления и автозапуск.
- [ ] Проверка macOS 14, Intel, разных экранов и длительной фоновой нагрузки.
- [ ] Дополнительная проверка доступности.
- [ ] GitHub Release с DMG, SHA-256, требованиями и списком изменений.
- [ ] Решение автора о лицензии проекта: сейчас файла LICENSE нет.

Homebrew, английский интерфейс и автообновления можно добавить после первого проверенного DMG; они не блокируют первую установку. Подробный порядок: [подготовка выпуска](INSTALLATION.md#что-осталось-для-удобного-публичного-выпуска).
