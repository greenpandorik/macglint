# Макеты MacGlint

Все изображения — оригинальные концептуальные макеты, созданные встроенным ImageGen в ходе обсуждения. Это растровые иллюстрации будущего интерфейса, а не скриншоты работающего приложения. Данные, процессы и время условные. Макеты не подтверждают доступность системных API.

## Выбрано: Air → MacGlint

Air — рабочее название выбранного направления. Публичное название проекта — **MacGlint**. Подписи в исходных изображениях сохранены как часть истории дизайна.

## Архив альтернатив

- [Calm](alternative-calm.png): спокойный виджет с крупными показателями.
- [Precision](alternative-precision.png): тёмный подробный монитор с графиками и таблицей.

Пользователь выбрал Air; альтернативы сохранены как история поиска направления, не как дополнительные режимы первой версии.

## Задания для генерации

- Air compact: нативная светлая панель macOS, полупрозрачная поверхность, русский интерфейс, CPU/память/сеть/батарея, малые графики, один основной потребитель ресурсов.
- Calm: тёплый светлый виджет, состояние «Всё спокойно», крупные показатели CPU и памяти, компактная строка сети.
- Precision: графитовая панель, метрики, история CPU за минуту, список процессов.
- Air expanded: развитие выбранного Air, раскрываемое дерево процессов Safari, поиск, сортировка, выбранный процесс и действие завершения; не придумывать названия вкладок.
- Air dark: сохранить компоновку раскрытого Air, заменить поверхности на графитовые, обеспечить читаемый светлый текст и синие акценты.

Приведены краткие описания заданий. Оригиналы изображений сохранены без изменений; при дальнейшем редактировании добавлять версии, а не перезаписывать выбранные референсы.
