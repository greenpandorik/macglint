# Проверка интерфейса MacGlint 0.2.0

14 октября 2026 года. Область: навигация, процессы, история, настройки, безопасные действия, клавиатура, светлая и тёмная темы. Сохраняем выбранное направление Air. Это практическая проверка нативного приложения; web-детектор не даёт содержательной оценки SwiftUI.

| Наблюдение в 0.1 | Изменение в 0.2 |
|---|---|
| Одно окно превращалось из мини-панели в большой интерфейс и скрывалось при потере фокуса | Раздельные мини-панель и обычное изменяемое окно; клик по значку переключает видимость мини-панели |
| Неочевидное «Подробнее», нет стандартного закрытия большого окна | Явное «Открыть полное окно», стандартные кнопки macOS; закрытие не выключает мониторинг |
| Слишком длинный список исключений отодвигал остальные настройки | Список свёрнут, есть поиск; сохранённые исключения доступны и для закрытых приложений |
| Текст с ошибкой в числовом поле мог сохранить старое значение | Отдельное текстовое состояние, объяснение ошибки и блокировка сохранения |
| Для приложения можно было выбрать неподдерживаемое правило | Только CPU и память, автоматическая корректировка при смене области |
| Родительская строка процесса реагировала только на мышь | Нативные кнопки с именами для доступности, Cmd+F, очистка поиска и закрытие карточки |
| Сортировка по памяти меняла группы, но не дочерние процессы | Одинаковая сортировка на обоих уровнях |
| Отказ в разрешении уведомлений оставлял бесполезную кнопку повторного запроса | Переход в настройки macOS и явный статус разрешения |

Автотесты покрывают некорректный и дробный ввод, неподдерживаемые метрики, сортировку дочерних процессов, размещение мини-панели на небольшом/смещённом экране, а также ранее существовавшие проверки метрик, правил, истории и защиты завершения процессов.

На macOS 26 / Apple Silicon проверены запуск мини-панели, переход в полное окно, Cmd+F, Cmd+,, просмотр выбранного процесса и запрет завершения самого MacGlint, обе темы, поиск исключений, история, закрытие мини-панели по Escape и работа процесса после закрытия полного окна. В редакторе ввод `abc` блокирует сохранение, `85,5` принимается; Cmd+0 сохраняет открытый черновик. Черновик отменён без изменения правил. В истории убран перенос подписи периода. Настройки темы возвращены к исходным.

Автоматизация нативного интерфейса проверяла переход к мини-панели через меню/клавиатуру; физический клик по значку строки меню отдельно не автоматизирован. Проверки малых экранов пока покрывают геометрию панели, а не все варианты дисплеев и выреза камеры.

Визуальные проверки проводят на реальных локальных данных, которые не добавляются в репозиторий. Наличие имён доступности не означает полную сертификацию VoiceOver. Проверка на macOS 14/Intel и чистом Mac остаётся частью подготовки публичного выпуска; подпись Apple и достоверное сопоставление вкладок Safari в этот этап не входят.
