# Возможности MacGlint 0.4.0

MacGlint — нативный монитор macOS в строке меню. Проект в первую очередь создаётся для личного использования, с помощью ИИ. Ниже описаны функции рабочей сборки, а не обещания из ранних макетов.

[Установка](INSTALLATION.md) · [Что ещё предстоит сделать](ROADMAP.md) · [English overview](../README.md)

## Быстрый обзор

- Клик по значку в строке меню открывает мини-панель; повторный клик, Esc или клик вне панели закрывает её.
- В панели: загрузка CPU, память и давление на память, входящая и исходящая скорость сети, заряд и питание батареи, свободное место на системном диске, группа процессов с наибольшим CPU.
- В самой строке меню можно оставить CPU, использованную память, скорость скачивания или их сочетание. Если выключить все показатели, останется значок.
- Клик по CPU или памяти открывает список процессов с соответствующей сортировкой. Шестерёнка открывает настройки.
- Правый клик по значку даёт доступ к мини-панели, полному окну, настройкам и выходу.

## Полное окно и оформление

Отдельное изменяемое окно с разделами «Процессы», «Рост памяти», «История», «Настройки». Его можно закрепить поверх других окон. Светлая, тёмная и системная темы поддерживаются в обоих режимах.

Стандартная красная кнопка macOS закрывает только окно: мониторинг продолжается. «Мини-панель» убирает большое окно и возвращает компактный обзор. «Выйти» завершает приложение и прекращает сбор данных. Повторный запуск приложения открывает полное окно, если значок потерялся среди других значков строки меню.

В 0.4.0 настройки разделены на «Основные», «Уведомления» и «О приложении»; списки и подписи стали компактнее. Дополнительного крестика внутри полного окна нет.

## Приложения и процессы

- Группировка процессов по приложению с раскрытием отдельных процессов.
- Поиск по приложению, имени процесса или PID; сортировка по CPU и памяти.
- Фильтр «Только мои» для процессов текущего пользователя.
- Сведения о выбранном процессе: PID, состояние, путь, CPU, память и график CPU за последние две минуты текущего сеанса.
- Обычное завершение и принудительное завершение с подтверждением. Доступны только разрешённые процессы текущего пользователя; MacGlint не завершает себя или PID 1. Перед действием повторно проверяются владелец и время запуска, чтобы старый PID не указал на другой процесс.

CPU во всех разделах — доля мощности **всего Mac**, от 0 до 100%. Поэтому значения отличаются от шкалы «Мониторинга системы», где процесс может использовать более 100% за счёт нескольких ядер. Память процессов — физический footprint; сумма по приложениям не обязана совпадать с общей использованной памятью.

## Подробная история

- До 24 часов локальных измерений. Периоды просмотра: 15 минут, час и сутки.
- Графики CPU, использованной памяти, давления на память, входящей скорости сети и свободного диска.
- Отметки сработавших правил на графике, список событий и переход к моменту события.
- Выбор момента нажатием на график, предыдущий/следующий срез и возврат к последнему измерению.
- Для записанных срезов: состояние Mac и наиболее нагруженные группы приложений/процессов. Сохраняется объединение трёх лидеров по CPU и трёх по памяти текущего пользователя — до шести групп, а не полный архив всех процессов.
- Системные точки записываются примерно раз в 10–12 секунд, сведения приложений — раз в 30 секунд. Новые алерты получают отдельный срез непосредственно при срабатывании.
- Переход из истории открывает текущий процесс только при совпадении его идентичности. Завершённый или перезапущенный процесс нельзя открыть по старому PID.

Подробности приложений накапливаются начиная с 0.3.0. Старые события остаются читаемыми без выдуманных данных. Пропуски после сна или остановки мониторинга не превращаются в нулевую нагрузку. Срез показывает наблюдения, но сам по себе не доказывает причину замедления.

## Рост потребления памяти

Отдельный список показывает приложения и группы процессов, у которых выросло потребление: сколько было, сколько стало, прибавка и фактический период сравнения. Есть поиск и переход к текущему процессу.

Сравниваются непрерывные наблюдения текущего сеанса за период **до 10 минут**, минимум — одна минута. Показывается рост от 1 МБ. При отсутствии измерений, полном перезапуске группы или длительном перерыве база сравнения сбрасывается. Изменения состава процессов отмечаются отдельно: рост может быть связан с появлением новых процессов. Это наблюдение за памятью, а не автоматический диагноз утечки. После выхода из приложения база сравнения не сохраняется.

## Правила и уведомления

| Область правила | Доступные показатели |
|---|---|
| Весь Mac | CPU, использованная память, давление на память, свободное место на диске |
| Выбранное приложение | CPU, память |

Для правила задаются название, порог, длительность нарушения и минимальный интервал между повторными срабатываниями. Для свободного диска срабатывает условие «меньше порога», для остальных показателей — «не меньше порога». Короткий скачок не вызывает событие. Пока уже обнаруженная проблема непрерывно сохраняется, одинаковые события не создаются на каждом измерении; повторное срабатывание учитывает восстановление и заданный интервал.

Правила можно включать, изменять и удалять. Есть исключения приложений, общая пауза на час и пауза отдельного правила на час с досрочным возобновлением. Исключения не отключают правила для всего Mac. Пауза отключает **создание событий и доставку уведомлений**, а не только баннеры.

Разрешение macOS на уведомления запрашивается по действию пользователя. Без него или при выключенных баннерах события продолжают сохраняться в истории, если правила не на паузе. Нажатие на доставленное уведомление открывает соответствующее событие.

## Карточки событий

Карточка содержит время, измеренное значение, исходный порог и длительность правила, состояние Mac и сохранённые группы приложений. Можно открыть ещё работающий процесс, изменить текущее правило или поставить его на паузу. Если правило уже удалено, событие остаётся в истории, а недоступные действия отключены. Для старых событий без среза показывается пояснение.

**Ни одно правило не завершает процессы автоматически.**

## Настройки и данные

- Настраиваемая строка меню, три варианта темы, управление баннерами и правилами.
- Необязательный запуск при входе в macOS: сначала установите приложение в «Программы».
- Очистка истории с подтверждением.
- Данные и настройки остаются на Mac; приложение не отправляет измерения на сервер или в ИИ. Внешние ссылки открываются только по вашему действию.
- История сохраняется примерно раз в минуту и при обычном выходе. При аварийном завершении последняя минута может не сохраниться.
- Мониторинг должен работать, чтобы записывать историю и обнаруживать превышения. Во время сна или после выхода измерений нет.

## Сочетания клавиш

Работают, когда активно приложение MacGlint; это не глобальные горячие клавиши.

| Клавиши | Действие |
|---|---|
| ⌘0 | Перейти в мини-панель |
| ⌘1 | Открыть полное окно |
| ⌘, | Открыть настройки |
| ⌘F | Найти процесс в разделе «Процессы» |
| ⌘W | Закрыть полное окно, продолжить мониторинг |
| ⌘M | Свернуть полное окно в Dock |
| ⌘Q | Полностью выйти |
| Esc | Закрыть мини-панель или отменить редактор правила |

Открытый редактор правила не скрывается при переходе к мини-панели.

## Чего пока нет

Точной привязки ресурсов к вкладкам Safari и управления вкладками; скорости сети по каждому приложению; GPU, температур и управления вентиляторами; истории за семь дней и экспорта; автоматического поиска утечек; условной тишины «пока открыт Figma»; английского интерфейса; автоматических обновлений и Homebrew cask.

Сборка 0.4.0 проверена на Apple Silicon / macOS 26. Минимальная заявленная система — macOS 14, но проверка на ней и на Intel ещё предстоит. Публичного GitHub Release и дистрибутива с Developer ID и нотариализацией Apple пока нет. [Текущее состояние установки и план выпуска](INSTALLATION.md).
